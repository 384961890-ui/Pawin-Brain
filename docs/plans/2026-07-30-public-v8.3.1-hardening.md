# Public Brain v8.3.1 hardening plan

> Scope: repair the existing public v8.3 release without adding post-v8.3
> features or private runtime data.

## Release gates

1. Source code and user data use separate directories by default.
2. Legacy clone-as-runtime installs remain protected by a deny-by-default
   `.gitignore`.
3. Claude Code, Codex, and ZCode pass fresh-home, repeat-install, path-with-
   spaces, permissions, and lifecycle tests.
4. Every session-derived path uses a bounded sanitized session identifier.
5. Codex runtime packaging reads an exact file allowlist and rejects unknown
   runtime files.
6. Tests and doctor checks are read-only unless an explicit repair/bootstrap
   command is requested.
7. The repository and generated package pass secret, local-path, runtime-data,
   and version-boundary scans.

## Delivery

- Work on a review branch.
- Rebuild the Codex runtime only after source fixes are complete.
- Validate from a second fresh clone of the review branch.
- Publish through a pull request; create an immutable `v8.3.1` tag only after
  the pull request is approved and merged.
